# Alarm

#Tools and packages

1. get – State management & navigation
2. hive – Lightweight and fast key-value database
3. hive_flutter – Hive integration for Flutter apps
4. android_alarm_manager_plus – Schedule Dart callbacks (alarms) in the background
5. flutter_local_notifications – Display notifications locally when the alarm triggers
6. omni_datetime_picker – date and time picker widget
7. get_storage – Simple persistent key-value storage, perfect for caching
8. permission_handler – Handles app permissions like alarm, notifications, etc.
9. path_provider – Access device paths for storing files and databases
